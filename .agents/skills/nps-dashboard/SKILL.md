# NPS 仪表板

确认代表推荐意愿的 0–10 字段、时间字段（需要趋势时）、分组及报告格式。多个字段或周期口径都合理且会改变结论时先问。使用用户指定的数据，保留源表，不依赖未获授权的外部服务。

1. 按 [Bain 的 NPS 口径](https://www.netpromotersystem.com/about/measuring-your-net-promoter-score/) 分类：9–10 推荐者，7–8 中立者，0–6 贬损者。空值、非整数和超出范围分别记为无效；去重仅按明确的记录键和规则。报告排除数量及理由，核对有效数与三类之和。
2. 按每个筛选和分组条件，用全部有效回答（包括中立者）计算 `100 × (推荐者数 − 贬损者数) / 有效数`。有效数为零显示「无有效样本」，不是 0 分。汇总从计数重算，不平均组分；采用用户指定的加权口径才另算加权分并标注。比较变化用点数，不假设变化有统计意义。
3. 默认展示总分、三类占比、有效样本量；有可比数据时再加趋势和主要分组。显示筛选和时间口径，标记小样本，样本不适合细分时聚合。解释数据覆盖限制和观察到的变化，不由分数推断原因，不展示不必要的个人级数据。
4. 交付前独立重算总计和至少一个分组；检查空样本情况、筛选联动和低样本标记。用户指定表格、HTML 或文本时使用对应格式；不能生成可用制品时，明确仅交付汇总或规格。

交付仪表板或报告、计算口径、主要发现和核对结果。例如 5 条有效回答为 10、9、8、6、0 时，NPS 为 0；另一个没有有效回答的分组应显示为空。
