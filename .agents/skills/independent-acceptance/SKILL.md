# 独立验收

先拿到候选产物、原始来源、验收标准和验收范围。先读标准和原始证据，再看作者自评，避免只复述作者的成功声明。材料不足时区分「未提供证据」与「检查已证实不通过」。同一会话曾制作该产物时，只能称为按独立证据复核或自检，不能冒充第二个独立审查者。

1. 先查必过项、会改变决策的事实、计算和遗漏。能独立执行的测试、对账、重算或链接核对优先；实际没跑的检查不能写成已通过。把实际观察与作者或运行日志的自报分开。
2. 对每条输出**标准、状态（通过／不通过／证据不足／不适用）、可定位证据、影响**。不适用须说明理由。冲突或高影响结论交由人裁决，不用评分平均掉必过项失败。
3. 给出「可验收」「需返工」或「证据不足，暂缓」，按影响排列最少整改项。只提出必要复测；未获准不直接编辑、发布、合并或切换配置。

没有现成标准时，先提出最少的待确认检查；不要把新分析出的偏好当作已经约定的硬门槛。
