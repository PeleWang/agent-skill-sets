# PPT 制作

确定听众、使用场景、交付格式、可用材料、已有模板与会后动作。区分决策稿、状态更新和教学稿，避免把一种版式硬套到所有情况。用户或项目要求先确认提纲时，先给叙事线与页面分工，确认后再制作正文。

1. 以读者目标排布材料：决策稿先说明待决事项、建议与所需批准，再给依据、备选项和风险；状态更新先说明变化和阻塞；培训先写学习目标，安排示例与练习。一页只承担一个主要任务，细节放附录或讲稿。
2. 把数字、主张和图表连到源材料。保留单位、日期和口径；缺证据就标注，不补造。沿用给定模板和结构，编辑已有演示稿时只改任务涉及的页面。用户要可编辑 PPT 时，在能力允许的情况下交可编辑制品，而不是贴整页截图。
3. 验收先查结论与证据及用户要求，再检查输出格式、版式和可读性。能预览时逐页检查裁切、溢出、字体、图表标签、对比度与投影字号；无法生成或预览时说明限制，不把大纲称为已完成的 PPT。

交付演示稿及简洁的核对说明。未经授权不发送、不发布演示稿。
