# 按个人偏好写作

先弄清任务简报、事实来源、目标读者和这次要写的体裁。只使用用户提供或允许使用的写作样例和规则，不自行翻查历史记录。需要先确认提纲时，根据读者是谁、要帮助他们做什么决定来拟提纲，确认后再动笔。

1. 从用户认可且与本稿可比的样例中找出适用的偏好：开头怎么说结论、每段放多少信息、用什么词和语气、怎样给出证据、哪些写法总被否决。区分明确提出的要求、多个样例都体现的偏好和只出现过一次的线索；体裁不一致时，以本次要求为准。
2. 按这些偏好重新组织当前材料，不照抄样例的句子，也不把样例里的事实带入本稿。重要事实必须有据可查；证据不足时明确注明，不用好听的话掩盖。改写时，保留用户没有要求改动的立场和信息。
3. 交付前按两三条最相关的风格和事实要求核对稿件。重要偏好仍不明确时，说明按什么合理假设写的，不用长篇自我评价代替正文。只撰写或修改要交付的内容，不擅自把这次的偏好保存为通用规则，也不替用户发送或发布。
