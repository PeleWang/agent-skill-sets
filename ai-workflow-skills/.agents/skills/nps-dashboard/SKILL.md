# NPS 仪表板

确认哪一列是 0–10 分的推荐意愿评分、哪一列是时间（需要看趋势时），以及如何分组、用什么格式出报告。如果有多个合理的字段或统计周期可选，而选择会影响结论，先向用户确认。使用用户指定的数据，保留原始表格，不依赖未经授权的外部服务。

1. 按 [Bain 的 NPS 计算标准](https://www.netpromotersystem.com/about/measuring-your-net-promoter-score/) 分类：9–10 分为推荐者，7–8 分为中立者，0–6 分为贬损者。空值、非整数和超出范围的评分分别记为无效；只按明确指定的记录标识和规则去重。说明排除了多少条记录及其原因，核对有效回答总数是否等于三类人数之和。
2. 对每种筛选和分组结果，用全部有效回答（包括中立者）计算 `100 × (推荐者数 − 贬损者数) / 有效数`。有效回答为零时显示「无有效样本」，而不是 0 分。汇总时根据人数重新计算，不对各组分数取平均；只有用户指定了加权方法，才另算加权分并注明。用相差多少分来描述变化，不直接认定变化有统计意义。
3. 默认显示总分、三类人数的占比和有效样本量；有可比数据时，再显示趋势和主要分组的结果。显示筛选条件和统计时段，标出样本量较小的组，数据不适合细分时合并展示。说明数据覆盖范围的局限和观察到的变化，不凭分数推断原因，不展示不必要的个人明细。
4. 交付前独立重算总体和至少一个分组的结果；检查没有有效样本时的显示、筛选后相关内容是否更新，以及样本量较小的组是否已标出。用户指定表格、HTML 或文本时，使用相应格式；无法生成可用的成品时，说明只能提供汇总结果或制作说明。

交付仪表板或报告、计算方法、主要发现和核对结果。例如 5 条有效回答的评分为 10、9、8、6、0 时，NPS 为 0；另一个没有有效回答的分组应留空。
