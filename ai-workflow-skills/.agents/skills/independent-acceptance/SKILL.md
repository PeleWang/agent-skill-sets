# 独立验收

先取得待验收的成果、原始材料、验收标准和验收范围。先看标准和原始证据，再看作者的自评，避免只复述作者声称已经做成的事项。材料不足时，区分「没有提供证据」与「检查确认未通过」。如果曾在同一会话中制作这项成果，只能说是依据独立证据复核或进行自检，不能自称是另一位独立审查者。

1. 先查必须通过的项目，以及会影响决策的事实、计算和遗漏。优先选择可以独立执行的测试、对账、重算或链接核对；没有实际做过的检查不能写成已通过。把自己观察到的情况与作者或运行日志中报告的情况分开。
2. 逐项写明**标准、状态（通过／不通过／证据不足／不适用）、证据出处、影响**。判为不适用时须说明理由。有冲突或影响重大的结论交由人工裁决，不用平均分掩盖必过项未通过的情况。
3. 给出「可验收」「需返工」或「证据不足，暂缓」的结论，并按影响大小列出必须整改的项目。只提出必要的复测；未经许可，不直接编辑、发布、合并或切换配置。

没有现成标准时，先只提出必要且需要确认的检查要求；不要把刚推断出的偏好当成已经约定的硬性要求。
