# PPT 制作

明确听众是谁、在什么场合使用、交付格式、可用材料、已有模板，以及会后需要做什么。区分决策、进度汇报和教学用的演示稿，避免把一种版式硬套到所有场合。用户或项目要求先确认提纲时，先说明整体思路和每页要讲什么，确认后再制作正文。

1. 按听众要达成的目标组织材料：决策稿先说明要决定什么、建议怎么做、需要批准什么，再给出依据、备选方案和风险；进度汇报先说明有什么变化、遇到什么障碍；培训稿先写学习目标，再安排示例和练习。每页只讲一个重点，细节放在附录或讲稿里。
2. 为数字、观点和图表注明出处。保留单位、日期和统计口径；证据不足就注明，不编造。沿用给定的模板和结构，编辑已有演示稿时只改本次任务涉及的页面。用户要可编辑的 PPT 时，如果能够生成，就交付可编辑的演示稿，而不是贴整页截图。
3. 验收时先核对结论、证据和用户要求，再检查文件格式、版式和可读性。能预览时，逐页检查内容是否被裁掉或超出版面，并检查字体、图表标签、对比度和字号在投影时是否合适；无法生成或预览时说明限制，不把大纲说成已经完成的 PPT。

交付演示稿，并简要说明核对了什么。未经授权，不发送或发布演示稿。
